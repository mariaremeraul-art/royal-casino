# Royal Casino

Casino educativo publicado en [https://casino-educativo.netlify.app](https://casino-educativo.netlify.app).

El código de acceso del dueño no está en este repositorio. Hay que configurarlo en Netlify, en la variable de entorno `OWNER_CODE`.

La carpeta `casino-royale/` guarda una versión anterior del proyecto. Las fuentes de la mesa de blackjack en 3D están en `tools/bj3d/`.
